# DFD Agency — website and client portal

Customer-facing website for DFD Agency: the public landing page, bilingual
order flow, client portal, and admin back office.

This repository contains **only the frontend**. The Go API lives in
[`davinakmalyasha/AgentsProxy`](https://github.com/davinakmalyasha/AgentsProxy).

## Stack

- Next.js 16 App Router, React 19, TypeScript
- Tailwind CSS v4, shadcn-style UI primitives
- `@dfd/shared` for shared Zod/API contracts
- Vercel for hosting; `/api/v1/*` is rewritten to AgentsProxy
- English and Indonesian routes under `/en` and `/id`

## Structure

```text
client/                 Next.js application
  src/app/(site)/[locale]
    page.tsx            landing
    client/             client login, dashboard, profile
    order/              order flow and success page
    p/[slug]/           public case studies
    terms/ privacy/     legal pages
    start/              locale-aware smart entry
  src/app/(admin)/admin Admin back office (English, /admin)
  src/components/       landing, order, portal, chat and UI components
  src/i18n/             dictionaries, locale config and provider
shared/                 @dfd/shared API schemas/types
```

## Local development

Requirements: Node.js 20+ and npm 10+.

```bash
npm install
npm run dev
```

The client runs at `http://localhost:3000`.

For local API development, point the client's rewrite/API base at the Go
backend (`http://localhost:8080/api/v1`). Production builds rewrite
`/api/v1/*` to the deployed AgentsProxy automatically and ignore an explicit
target that is not the production backend; previews stay fail-closed unless a
non-production target is configured.

### Environment

Set these in `client/.env.local` as needed:

```dotenv
# Optional in production; server-side fallback is the deployed API
NEXT_PUBLIC_API_URL=http://localhost:8080/api/v1

# Google one-click login
NEXT_PUBLIC_GOOGLE_CLIENT_ID=

# Cloudinary loader
NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=

# Canonical origin for metadata/sitemap when not on Vercel
NEXT_PUBLIC_SITE_URL=https://dfdagency.vercel.app
```

Never commit `.env`, `.env.local`, or other environment files containing
secrets.

## Deployment

- Frontend: Vercel project `dfd-agency-website` → `https://dfdagency.vercel.app`
- API: Vercel project `agents-proxy` → `https://agents-proxy-nine.vercel.app`
- Locale cookies are first-party. `/` negotiates to `/en` or `/id` based on
  saved preference and Vercel country detection.
