# DFD Agency client app

Next.js frontend for the DFD Agency website and client portal.

- Public landing and case studies
- English `/en` and Indonesian `/id` routes
- Client login, dashboard, profile, orders and legal pages
- Admin back office at `/admin`
- `/api/v1/*` is proxied to AgentsProxy

See the [repository README](../README.md) for setup, environment variables,
commands and deployment.

```bash
npm install
npm run dev
```

Production: [dfdagency.vercel.app](https://dfdagency.vercel.app)
